# 「树洞来信」MVP 实施计划

日期：2026-07-16

依据：[MVP 设计规格](../specs/2026-07-16-tree-hole-letter-mvp-design.md)

## 交付目标

交付一个可公开访问、可由真实用户完成邮箱登录、写信、封存、等待、邮件提醒与启封的手机端网站。验收对象包含前端、后端、数据库迁移、邮件任务、自动化测试、Vercel 生产部署和中文运维文档，不以静态 Demo 代替。

## 阶段 1：工程基线

- 初始化 Next.js App Router、React、TypeScript、Tailwind CSS 和 ESLint。
- 配置 Vitest、Testing Library、Playwright、严格 TypeScript 和环境变量校验。
- 建立按功能拆分的目录、统一错误响应、日志脱敏和 CI 脚本。
- 提供 `.env.example`，禁止任何真实密钥进入 Git。

验收：本地开发、类型检查、Lint、单元测试与生产构建均能执行。

## 阶段 2：复古书信 UI

- 建立木桌、信纸、信封、封蜡、邮戳、纸质标签等设计令牌和组件。
- 完成首页、登录、写信、我的树洞、信件详情和设置页。
- 完成长按封存的普通按钮替代、减少动态效果、安全区域和移动端适配。
- 遵循 WCAG 2.2 AA，并避免把长正文设置为手写体。

验收：375px、390px、430px 及桌面居中布局无横向溢出；键盘、屏幕阅读器与减少动态效果路径可用。

## 阶段 3：数据库与安全核心

- 编写 Supabase SQL 迁移：`profiles`、`letters`、`reminder_deliveries`、约束、索引和默认拒绝策略。
- 建立集中式 Service Role 数据访问层，所有用户查询强制携带已认证用户 ID。
- 实现 AES-256-GCM 正文加密、版本化 keyring、独立 HMAC 幂等密钥和日志脱敏。
- 实现创建幂等、日期原子修改、永久删除和账号 `active/deleting` 门禁。

验收：跨用户访问、密文篡改、错误密钥、重复提交和并发日期修改测试全部通过。

## 阶段 4：认证与信件闭环

- 实现 Next.js OTP 请求与验证端点、安全 Cookie 会话和站内安全重定向。
- 接入 Supabase Auth，并在服务商侧启用 CAPTCHA 与速率限制。
- 实现写信、会话草稿、提交结果对账、列表、显式 POST 启封、重读和删除。
- 实现退出登录、账号删除和部分失败补偿。

验收：真实邮箱登录和完整信件流程可运行；GET、预取或链接预览不能提前启封。

## 阶段 5：邮件提醒

- 接入 Resend，使用不含标题或正文的通用提醒邮件。
- 实现 Vercel Cron、事件键、发送租约、稳定幂等键、失败分类和有限重试。
- 实现站长可诊断日志，不向普通用户开放滥用型重试接口。

验收：测试时钟到期、重复 Cron、任务崩溃恢复、终止错误和真实提醒邮件均验证通过。

## 阶段 6：全面测试

- 单元测试：日期、时区、闰日、加密、HMAC、校验和状态机。
- 集成测试：授权、数据库原子性、幂等、账号删除和提醒租约。
- 端到端测试：登录、草稿、封存、响应丢失对账、启封、删除和移动端流程。
- 安全测试：越权、开放重定向、OTP 滥用、敏感字段泄露和环境变量暴露。
- 可访问性与性能检查：axe、键盘路径、缩放、减少动画、Lighthouse。

验收：`npm run test:all`、`npm run build`、Playwright 关键路径和生产 smoke test 全部通过。

## 阶段 7：云端资源与部署

- 创建 GitHub 私有仓库并推送经过测试的提交。
- 创建 Supabase 项目，执行迁移并配置 Auth/CAPTCHA。
- 创建 Resend API key；零成本阶段仅向账号本人发送。
- 创建 Cloudflare Turnstile widget。
- 创建 Vercel 项目，配置环境变量、Cron 和生产部署。

验收：公网链接可访问，生产数据库权限生效，密钥不出现在客户端或仓库。

## 阶段 8：生产验收与交接

- 在生产环境完成一次真实 OTP、写信、短期测试到期、提醒与启封。
- 使用手机视口和真实移动浏览器验证核心路径。
- 检查错误日志、提醒失败恢复和账号删除。
- 输出中文部署、密钥轮换、备份升级、域名接入和短信迁移说明。
- 清晰标注免费体验版无法承诺五年或十年持续可用。

最终完成条件：前后端代码、数据库、提醒、测试、文档和公网链接全部存在，并有可复核的生产验收证据。
